주관식 암송 테스트

문제 입력 → 문제 만들기 → 시험 → 채점 · PDF 문답지 추출 기능 추가
※ 기본 암송 테스트는 로컬에서 실행됩니다. PDF 읽기 기능은 PDF.js 라이브러리를 불러오기 위해 인터넷 연결이 필요합니다. 기기에 저장한 뒤 HTML 실행을 지원하는 브라우저 또는 로컬 HTML 실행 앱에서 여세요. ChatGPT 미리보기에서는 버튼이 동작하지 않을 수 있습니다.

1. 문제 입력

정답이 포함된 문제를 그대로 붙여넣으세요.
예: (① 일곱째 천사)처럼 ①~⑳ 번호와 정답이 있으면 자동으로 인식합니다.

PDF 문답지에서 문제·정답 추출

PDF에서 정답을 먼저 별도로 보관한 뒤, 정답이 보이지 않는 시험지를 만듭니다. 시험이 끝나면 보관한 정답 기준으로 채점합니다. 텍스트형 PDF를 지원하며 암호가 있는 PDF는 암호를 입력할 수 있습니다.

정답은 화면에 표시하지 않고 메모리에 보관해 채점에 사용합니다. 스캔 이미지 PDF는 아직 지원하지 않습니다.

2. 문제 확인

초록색 부분이 정답으로 인식된 구멍입니다. 필요하면 아래 정답을 직접 수정할 수 있습니다.

수동 구멍 지정

단어를 눌러 선택하세요. 최대 20개까지 선택할 수 있습니다. 선택한 원문이 정답으로 저장됩니다.

3. 시험

키보드로 입력하거나, 태블릿의 펜 손글씨 입력 기능을 사용하세요. 시험 중에는 정답이 표시되지 않습니다.
